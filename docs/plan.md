# 赞助插件任务计划

日期：2026-11-10

状态：用户已确认识别主动赞助意图并要求继续。进入实现和验证。

## 已明确的目标

- 为 AstrBot 提供赞助信息发送功能。
- 支持指令触发和对话触发。
- 发送管理员预先设置的收款码或赞助链接。
- 使用会话白名单或黑名单控制启用范围。
- 交付实现、配置说明和验证结果。

## 已确认的会话名单规则

| 模式 | 名单情况 | 是否在该会话启用 |
| --- | --- | --- |
| 白名单 | 为空 | 否，所有会话均不启用 |
| 白名单 | 非空，当前会话在名单内 | 是 |
| 白名单 | 非空，当前会话不在名单内 | 否 |
| 黑名单 | 为空 | 是，所有会话均启用 |
| 黑名单 | 非空，当前会话在名单内 | 否 |
| 黑名单 | 非空，当前会话不在名单内 | 是 |

“启用”仅表示允许在该会话使用插件，不表示收到任意消息就发送赞助信息。
发送仍须满足指令或对话触发条件。

沿用此前建议的实现设计：

- 名单使用 AstrBot 完整会话标识，区分平台、群聊和私聊。
- 两类触发入口共用名单检查，禁止的会话不会发送赞助信息。
- 默认使用白名单，初始名单为空。

## 触发与发送设计

- `/赞助`，别名 `/sponsor`、`/打赏`，直接发送已配置的全部赞助信息。
- LLM tool 仅识别用户主动索要赞助方式、收款码、赞助链接等意图。
- 工具描述明确排除拒绝赞助、闲聊、引用他人话语和索要他人收款方式。
- 不额外调用模型判断意图。复用当前 AstrBot 对话的工具调用能力。
- 两个入口共用配置校验、会话名单和发送逻辑。
- 使用 AstrBot 通用文本、图片消息组件，适用于具备这些能力的平台；不宣称已验证全部平台。
- 配置一段文案、图片列表和链接列表。请求时发送全部有效配置，不引入订单、支付或到账流程。
- 图片支持 HTTP(S) 地址和本地文件。相对路径以插件数据目录为根，禁止相对路径越界；绝对路径由管理员明确填写。
- 链接只接受不含凭据、空白或控制字符的 HTTP(S) URL。
- 同一事件只尝试发送一次，覆盖并发工具调用。发送异常后不自动重试，避免不确定送达时重复发送。
- `/赞助状态` 仅机器人管理员可用，不受名单限制，用于获取当前会话标识和检查配置。它不返回收款内容或本地路径。

## 文件与实现任务

目标：提供可安装的 AstrBot 赞助信息插件。

架构：`sponsor.py` 使用标准库完成会话规则和配置校验；`main.py` 负责 AstrBot 接入和发送。测试通过公开行为验证规则，发送边界使用离线替身，并单独标注真实 SDK、模型和平台状态。

技术：Python 3.10+、AstrBot 4.9.2+，无额外运行依赖。

## 验收基线

- 指令和对话入口均能发送已配置的赞助内容。
- 赞助内容来自插件配置，用户消息不能改写收款目标。
- 未配置时不发送虚构链接或收款码。
- 对话入口遵循最终确认的触发范围。
- 名单规则符合上述六种情况，尤其保证两种模式下空名单的行为相反。
- 明确区分离线测试、AstrBot 加载和真实平台发送的验证结果。

## 首版范围

首版聚焦展示赞助信息。支付状态查询、到账通知、订单管理和赞助排行不在本次实现范围。
